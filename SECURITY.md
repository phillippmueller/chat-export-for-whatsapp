# Security policy

## Reporting a problem

If you find a security problem, for example a way the tool could leak message
data, write outside the chosen export folder, change WhatsApp's own data, or
run code it shouldn't, please report it privately rather than in a public
issue:

- **Preferred:** use GitHub's private
  [Report a vulnerability](https://github.com/phillippmueller/chat-export-for-whatsapp/security/advisories/new)
  form.
- **Or email:** [philip.mueller.bueckeburg@gmail.com](mailto:philip.mueller.bueckeburg@gmail.com) with "Security" in the subject.

Please include what you did, what happened, and the output of
`whatsapp-export.sh version`. Never include real messages. You'll get a first
reply within 7 days.

## Supported versions

Only the latest release receives fixes.
